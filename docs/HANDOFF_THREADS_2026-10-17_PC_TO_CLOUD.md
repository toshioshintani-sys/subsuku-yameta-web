## 1. 目的（変えないでください）

**世の中にすでにある日本の Threads のバズ投稿を500件以上集めて、傾向を分析する。**その結果で、サブスクやめたの Threads を伸びる投稿で再開する。

俊雄さんから、今日はっきり言われたことが3つあります。どれも絶対です。

1. **目的を差し替えない。**障害が出ても、「自分の投稿で試す」などの別の目的に置き換えない。手段の選択肢だけを並べる。（私は一度これをやって、強く叱られました）
2. **500件の数字を勝手に下げない。**これは「AI が手近な少数だけ拾って、やったふりをする」のを防ぐための決まりです。500件そろうまで分析はしない。
3. **探すのは AI。**俊雄さんに目視させたり、クラウドワーカーに頼んだりする案は出さない。（私はこれも3回やって、「いい飽きた」と言われました）

もう一つ、「見つけることを今は頑張っているけど、目的は違うところにあるのを忘れないで」とも言われています。集めるのは手段です。

## 2. 公式 API の審査申請：送らない

詳しくは `docs/THREADS_APP_REVIEW_2026-10.md` にあります。理由は2つです。

- 他人の公開投稿を検索するには、`threads_keyword_search` の審査の承認が要ります。承認（高度なアクセス）には**ビジネス認証**が要ります。俊雄さんは個人で、事業の登録がありません。
- 承認されても、**検索で取れる他人の投稿には、いいね数も表示数も付きません。**数字（インサイト）は自分の投稿だけです。

その他の事実：
- `threads_manage_insights`（自分の投稿の成績）は、テスターの @sabusuku.yameta なら**審査なしで使えます**。ただし権限の追加とトークンの作り直しは、まだしていません（俊雄さんの操作が要ります）。
- Meta の開発者画面は、今日は PC の Chrome でどのページも読み込みが終わりませんでした。フォームには何も入れていません。
- 申請用の英語の説明文・録画台本・プライバシーポリシーの追記案は、記録として残してあります（今は使いません）。

## 3. 集め方の調査と規約（ここが一番大事）

全体は `docs/THREADS_BUZZ_SOURCES_2026-10.md` にあります。調査役のべ約20人と、私の検索・実測をまとめたものです。

**Meta 利用規約 3.2（2025-01-01 適用・日本語版の原文で確認）**は、次の2つを禁じています。どちらも「ログインしているかどうかを問わない」と明記されています。

- 自動化手段で Meta 製品のデータにアクセス・取得すること
- Meta のサービスから取得されたデータを**販売・ライセンス供与・購入**すること

このため、次の道は使いません。

| 使わない道 | 理由 |
|---|---|
| threads.com を AI が読む（どの AI でも同じ） | 自動収集の禁止 |
| 収集業者（Apify・Bright Data など）から買う | データの購入の禁止。業者は米国の裁判で勝っているが、それは集めた側の話。Meta は買う側の利用者の違反も問題にしている |
| Chrome 拡張で、見た画面を記録 | 自動収集の禁止。俊雄さんのアカウントで動く |
| Google 検索を機械的に回す | Google の規約。実際、10回目からの連続検索は安全確認に止められた |
| 人（俊雄さん・クラウドワーカー）に探させる | 俊雄さんの決まり（§1の3） |

止められうるのは、@sabusuku.yameta を含む俊雄さんの Meta 系のアカウントです。サイトの「正直」の看板とも合いません。

## 5. まだ解けていないこと（クラウドで考えてほしい）

### 5-1. 文字だけの大喜利が集まらない
ねとらぼの記事は、ほぼすべて**写真つきの投稿**です（弁当・子ども・ペット・驚きの一枚など）。
俊雄さんが「日本の Threads で伸びる」と見ている文字の大喜利・お題・一言ボケは、ほぼ入りません。
このまま500件で分析すると、「写真で伸びる型」に偏ります。作戦案（`docs/THREADS_OOGIRI_PLAN.md`）は文字の大喜利が中心なので、分析するときはこの偏りを必ず書いてください。

分かっていること：
- Google で `site:threads.com` を付けて検索すると、文字の投稿が「○件以上の高評価」（いいね数の目安）つきで出ます。家族の会話・職場・お金の話題で、1回の検索に約1件のバズ（いいね1,000以上）が拾えました（9回で7件）。ただ、機械的に回すと規約に触れます（§3）。
- ほ・とせなNEWS（「SNSで話題」タグ）も Threads の投稿を表示数つきで記事にします。ただ元の投稿へのリンクが無く、やはり写真中心です。
- 文字だけの大喜利を記事にする媒体、人が選んだ一覧、公開データセットは、どれも見つかりませんでした。

**規約に触れずに、AI だけで文字のバズ投稿を集める道を、引き続き探してください。**見つからない場合は、「AI には無理。理由はこれ」と短く報告してください。人の作業に置き換えた案は出さないでください。

### 5-2. 500件に届いたあと
1. `--rebuild-detail` で詳しい表を作る
2. 型の分析（写真の偏りを明記）
3. 作戦案（`docs/THREADS_OOGIRI_PLAN.md`・俊雄さんの決定待ち）に反映する
4. 実際の投稿へ

自分の投稿の成績を測るには `threads_manage_insights` が要ります（審査は不要。権限の追加とトークンの作り直しは俊雄さんの操作）。
