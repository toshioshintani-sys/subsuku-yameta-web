## 入れていないもの・理由
- **鮮度の年月（「2026年11月確認」など）**：依頼書の「実際に確認した年月だけを使う」を守るため。サービスごとの確認日を持つデータが無い（価格変更履歴の確認日は変更があったサービスだけ）。入れるなら、毎日の価格監視の確認日をビルドに渡す仕組みが先に要る。
- **Search Console のページ別データでの絞り込み**：クラウドから Search Console を読めないため、全サービスのテンプレートで一括対応した。個別に変えたいページが出たら `seoTitle` / `seoDescription`（services.js）で上書きできる。
- 依頼書の「やらないこと」（トップUI変更・誇張表現・代替提案を記事冒頭に置く・SNS/被リンク施策）は守った。

## 注意点（リスク）
- タイトルが長いサービス（例：gemini-advanced 56字）は検索結果で後半が切れる。差別化の語は前半に置いてある。
- タイトル変更直後は、順位が一時的に動くことがある。12月初めの Search Console（11月分）を基準に、2か月分で比べる。
