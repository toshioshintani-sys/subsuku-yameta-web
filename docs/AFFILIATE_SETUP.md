# アフィリエイト統合の設定手順（俊雄さん向け）

このドキュメントは「サブスクやめた」を実収益化するための手順をまとめています。
コード側は既に「ASP の追跡 URL を入れるだけで稼働する」状態に整っています。

---

## A. A8.net の設定（最優先）

### A-1. サイト追加（5分）

1. https://media-console.a8.net/registration-information/site にアクセス
2. 再認証画面が出たらログイン
3. 「新しいサイトを登録」をクリック
4. 入力：
   - サイト名：**サブスクやめた**
   - サイトURL：**https://sabusuku.netlify.app**
   - カテゴリ：**ライフスタイル / ハウツー**
   - 月間PV：開始間もないので「1000未満」で問題なし
5. 確認 → 登録完了

### A-2. 提携申請（10分）

A8 トップで「プログラム検索」から下記の案件を順に検索して、それぞれ「サブスクやめた」サイトで提携申請：

**動画系（最優先・単価高い）**
- U-NEXT（初回登録 1500-2000円/件）
- Hulu
- DAZN（2500-5000円/件）
- Lemino（旧dTV）
- dアニメストア

**読書・音声系**
- Audible（1500円/件）
- Kindle Unlimited
- 楽天マガジン
- 日経電子版

**ソフトウェア・SaaS**
- Adobe Creative Cloud（3000-8000円/件）
- Canva Pro
- Notion

**マッチングアプリ系（単価最高）**
- ペアーズ・with・マッチドットコム（5000-10000円/件）

### A-3. 提携承認後の手順

承認メールが届いたら：

1. A8 「プログラム管理」→ 承認済みプログラムを開く
2. 「広告リンク」→ 「テキスト」を選んで、表示された URL をコピー
3. このリポジトリの `src/data/affiliates.js` を開く
4. `ASP_FULL_URLS` オブジェクトに追加：

```js
export const ASP_FULL_URLS = {
  'u-next': 'https://px.a8.net/svt/ejp?a8mat=XXX+YYY+...',  // ← ここにコピーしたURL
  'hulu': 'https://px.a8.net/svt/ejp?a8mat=...',
  // ... 全ての承認済みプログラムを並べる
};
```

5. git commit / push → Netlify が自動デプロイ → 即座に収益化開始

## B. もしもアフィリエイトの設定

### B-1. サイト追加（5分）

1. https://af.moshimo.com/ にログイン
2. 「メディア運営ツール」→「メディア管理」
3. 「新規メディア登録」
4. 入力（A8 と同じ内容）
5. 登録完了

### B-2. 提携申請

特に「Amazon アソシエイト経由」のもしもプログラムが便利：

- Amazon プライム（もしも経由なら審査ハードル低い）
- 楽天市場（楽天Kobo・楽天マガジン・楽天ミュージック）
- Audible（A8 と併用可能）

### B-3. 設定方法

承認後、もしもの「広告リンク」で表示される URL をコピーして、
`src/data/affiliates.js` の `MOSHIMO_LINKS` か `ASP_FULL_URLS` に入れる。

---

## C. Amazon アソシエイト（簡単・即時）

A8 / もしも 経由でなく、Amazon に直接登録するルート：

1. https://affiliate.amazon.co.jp/ にログイン
2. 自分のアソシエイト ID（例：`subsuku-22`）を確認
3. Netlify 環境変数に追加：
   - Key: `VITE_AMAZON_ASSOCIATE_ID`
   - Value: `subsuku-22`（実際のIDに置換）
4. Trigger deploy

これで `services.js` の Amazon系リンク（Amazon プライム、Audible、Kindle Unlimited 等）が
自動的に `?tag=subsuku-22` 付きになる。

- **6ヶ月後**：月 5-15 万円
