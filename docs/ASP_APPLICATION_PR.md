## サイトPR（メイン・約350字）

Netflix・Spotifyなど58のサブスクリプションサービスの「解約手順」を3ステップで案内する、固定費見直しの実用サイトです。解約だけでなく、①契約中サブスクの年額合計を可視化する「棚卸しダッシュボード」、②ジャンル別に乗り換え先を比較する「サブスク図鑑」（8ジャンル）、③月額をやめて買い切りで済ませる代替案、までを一体で提供し、読者の固定費の意思決定を支援しています。解説記事は20本以上を公開し、週3本ペースで継続更新中です。紹介サービスは必ずデメリットも併記する両論併記を編集方針とし、ランキングや誇張表現は使用しません。全アフィリエイトリンクへのPR表記、収益開示ページ・運営者情報・お問い合わせ窓口を設置済みで、ステマ規制（景品表示法）に対応した運営を行っています。
