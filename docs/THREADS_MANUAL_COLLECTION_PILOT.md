# Threads の文字のバズ投稿を人の手で集める：20件の試験（準備・2026-10-17）

> 🛑 **取り下げ（2026-10-17 22時台・俊雄さん「探すのはAIです」）**：探す作業を人（俊雄さん・クラウドワーカー）に回す案は使わない。この文書は記録として残すだけ。

> 目的（変えない）：世の中の日本の Threads のバズ投稿を500件以上集め、傾向を分析する（`docs/THREADS_BUZZ_SOURCES_2026-10.md`）。
> ニュース記事（ねとらぼ）からは写真の投稿しか集まらない。**文字だけの投稿（大喜利・お題・一言ボケ・あるある）** をこの方法で補う。
> 業者や Chrome 拡張は使わない（Meta 規約 3.2 の自動収集・データ購入の禁止に当たるため）。人が普通にアプリやブラウザで見て、手で書き写す。
> 規約の「データの購入」にあたるかは解釈が分かれる（人の作業への支払いと見るか、データの購入と見るか）。この点を承知のうえで、まず20件だけ試す。

## 1. 試験の決まり（先に決めておく）
- 件数：**20件**（うち10件は話題を問わない文字の大喜利・お題・一言ボケ、10件はお金・節約・家計・固定費・サブスク・解約の話題）。
- バズの基準：**いいね1,000件以上**（参考にしたのは、バズ投稿30件を分析した note の基準「いいね1,000以上」）。表示数は投稿者本人にしか見えないので使わない。
- 文字だけの投稿に限る（画像・動画つきは除く）。
- 費用の目安：1件150円 × 20件 ＝ 3,000円＋手数料（ランサーズは5.5%）。
- 合格の基準：20件のうち18件以上が、URL で開いて基準どおり（文字だけ・いいね1,000以上・重複なし）と確かめられること。
- 合格したら、残りを同じ条件で頼むか決める（500件に足りない分）。不合格なら、この方法はやめる。

## 2. 依頼文（ランサーズ／クラウドワークスにそのまま貼る）

```
【タイトル】Threads（スレッズ）で「いいね1,000以上」の文字だけの投稿を20件、表にまとめてください

【お願いしたいこと】
Threads のアプリかブラウザで、ふだんどおりに投稿を見て、条件に合う投稿を20件探し、表に書き写してください。

【条件】
・文字だけの投稿（画像・動画が付いていないもの）
・いいねが1,000件以上
・日本語の投稿
・次の2種類を10件ずつ
  A. 大喜利・お題・一言ボケ・あるある など、笑いをとる投稿（話題は何でも可）
  B. お金・節約・家計・固定費・サブスク・解約 の話題の投稿（笑いでなくても可）
・同じ投稿を2回書かない

【探し方の例】
Threads の検索で「大喜利」「お題」「あるある」「サブスク」「節約」「固定費」などを入れ、「人気」の並びで探すと見つかりやすいです。

【表に書くこと】（1件につき1行・添付の表を使ってください）
1. 投稿のURL（投稿を開いて「リンクをコピー」したもの）
2. 投稿者のID（@から始まるもの）
3. 投稿の日付
4. 本文（そのまま全文）
5. いいねの数
6. 返信の数
7. 再投稿の数
8. 種類（A か B）
9. 探すときに使った言葉
10. 数を確かめた日時

【守ってほしいこと】
・自動で集める道具（拡張機能・スクレイピング・ツール）は使わないでください。手作業でお願いします。
・投稿に「いいね」や返信などの反応はしないでください（見るだけ）。
・ログインしたアカウントは、ご自身のふだんのもので構いません。

【報酬・支払い】
・1件150円（20件で3,000円）
・こちらで URL を開いて確かめ、条件に合った件数分をお支払いします
・最初の20件がよければ、追加で同じ作業をお願いするかもしれません

【納期】ご契約から5日以内
```

## 3. 記入表（列）
`post_url, author_id, post_date, text, likes, replies, reposts, kind(A/B), search_word, checked_at`

- 受け取った表は `scripts/ops/threads-buzz/data/` に置く（.gitignore 済み・公開リポジトリに他人の投稿を置かない）。
- 本文は社内の分析だけに使い、サイトや SNS に載せない。

## 4. 受け取ったあと私がやること（検算）
1. URL の重複を数える。
2. いいね数が1,000以上か、数字の書式がそろっているかを機械で調べる。
3. 20件すべての URL を、俊雄さんか私がブラウザで開いて、文字だけ・いいね1,000以上・本文が一致するかを確かめる。私は threads.com を自動では開かないので、私が確かめるのは手で1件ずつ開ける場合だけ。
4. 合格・不合格を §1 の基準で判定し、結果をこの文書に書き足す。
