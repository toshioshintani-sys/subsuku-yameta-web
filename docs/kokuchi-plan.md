# サブスクやめた 告知プラン（2026-06-01 朝報告用）

> 俊雄さん「ゲームもいいけど告知はどうする？4コマでもなんでも、告知ネタをまとめて朝に報告」への回答。
> 方針：あなたの手作業を最小に。素材は私が全部用意、あなたは「生成して1枚貼る」だけ。

---

## 0. 正直な結論（盛らない）
ゼロ観客・ゼロ予算の告知に魔法のボタンは無い。だが**4コマ画像**なら、動画より圧倒的に低手間（録画・編集・TTSなし＝画像1枚）。**4コマ＝撒き餌、ゲーム＝釣り上げ**のファネルが噛み合う。

```
4コマ（3秒・共感→オチ・バイアス名は出さない）
  → 弱い一言「で、あなたは？ 無料診断 sabusuku.netlify.app/games」
  → ゲーム（試す）→ サイト
```

## 1. チャネル（低手間×新規に優しい順）
| 順 | チャネル | 理由 | 手間 |
|---|---|---|---|
| ① | **note** | 4コマ＋短文と相性最強・SEOにも乗る・既にライフオラクルで運用知見あり | 画像＋数行 |
| ② | **Threads / X（画像投稿）** | 画像投稿はリンク投稿より抑制が緩い・Threadsは新規でも伸びやすい | 画像1枚 |
| ③ | **Pinterest** | 新規アカウントでも関連性だけで露出・4コマ/インフォ画像が恒久的に拾われる | 画像1枚 |
| ④ | YouTube Shorts（@subsukuyameta 開設済） | 検索で恒久・だが動画化は手間 → 後回し（自動生成が出来たら） | 中 |
| — | 検索/AIプル（私が記事・ゲームを積む） | 無料・複利・**あなたの手間ゼロ** | 私 |

**正直な制約**：サブスクやめた専用のSNSは今 YouTube だけ。①②③をやるには**サブスクやめた名義のnote/Threads/X/Pinterestを1つ作る**必要あり（アカウント作成は俊雄さんの作業／私はログイン・作成しない）。**まず1つだけ**作れば、素材は無限に私が供給します。

## 2. 悪態どら猫4コマ（標準フォーマット確定・2026-06-06 / proposal-stress-test通過）

### 🐱 運用憲法（崩さない／固定・可変・賭けの担保）

> **決定**：悪態大喜利4コマを Threads 告知の**標準フォーマット**に確定。本セクションの8本（ラーメン出汁／良い竹つかってんな／みんなって誰だよ級）を**品質の最低ライン**とする。
> **判断ライン（俊雄さん 2026-06-06）**：**100本出して1本も「1,000」を超えなければ**、ボイスでなく**チャネル/ターゲット仮説**を再考する（＝悪態が悪いのではなく、刺す相手か届け方を疑う）。

**固定（憲法級・絶対に崩さない）**
- **どら猫＝毒舌大喜利キャラ**：目を半分閉じたふてぶてしい野良猫。半笑いで急所を一言。刃は必ず「**サブスクの罠・業者・黙って差し出してる行動**」に向ける。
- **絶対線（越えたら通報→チャネル消滅）**：人格否定・「バカ/死ね」系・差別・脅迫トーンは禁止。殴るのは“行動と仕組み”だけ、読者の存在は殺さない。
- **構造**：4コマ目で殴る → **2投目（返信）で必ず手を差し出す**（診断/tracker＋UTM）。**煽りっぱなし禁止**。この落差で「毒舌だが味方」が成立する。
- §2-2（煽り・ランキング・★スコア禁止）と最上位原則（社会性＝収益の生命線）に従う。毒は**笑い（大喜利）で包む**から飲み込める＝拡散され、通報されない。

**可変（固定したら死ぬ）**
- **オチの型・比喩は毎回変える**（“養分かよ”を定型化しない。語彙バンクを育てる）。
- **悪態の強度はテーマで上下**（重い不安系は弱め、あるある系は強め）。

**賭けの担保（“いつかバズる”を願望で終わらせない）**
- **分布の種を足す**：Threads単独でなく X / Pinterest / 既存note読者へクロス（初速ゼロ対策）。
- **追う指標**：いいね総数だけでなく**2投目UTMクリック→診断到達**を併読（§3「スキ稼ぎを追うな」と同じ戒め。バズ≠目的、収益が目的）。
- **撤退ライン**：100本 × 1,000超えゼロ → 仮説再考。

### 🚨 広報運用ルール（炎上防止・対外ふるまい・2026-06-07 / proposal-stress-test通過）

> 広報部長提言＋俊雄さん指示（リプライ担当・自動リプライ）を stress-test で安全化して確定。**チャネル別ボイス**が大原則。

**チャネル別ボイス（最重要）**
- 悪態どら猫ボイスは **Threads の告知クリエイティブ限定**（＝「よく見るゲームCM」枠）。アプリ(sabusuku.netlify.app)・note・ブログ・図鑑・将来のXは**誠実トーンを維持**。毒を恒久露出メディアに資産化しない。
- ブランド名は全チャネル共通、**ボイスはチャネルで切り替える**。

**強度の物差し（1〜5）**
- 標準=3／あるある系=最大4／重いテーマ(健康・借金・不安)=最大2。
- **強度5（“養分”“毟る”級）は封印**。使う場合は投稿前に俊雄さん承認必須。

**実在サービス名の扱い**
- 攻撃は常に「仕組み・ダークパターン・“業者”一般」に向ける。事実（料金・自動更新仕様）は名指し可／評価・断定（ぼったくり等）で名指しは禁止。
- **提携先（A8/もしも案件）を悪態の標的にしない**（「業者を殴って業者で稼ぐ」偽善リスクの回避）。殴るのは引き止めダークパターン全般、紹介するのは“卒業→入学”の代替。

**リプライ運用（b2＝他者コメントへの対応・自動化の線引き）**
- ✅ 完全自動OK：賞賛・共感への**いいね**のみ（文は返さない）※API非対応なら無反応／明確なFAQ（診断どこ・解約方法）への**固定テンプレ**返信（運営トーン）。
- 🔶 半自動（人承認）：批判・皮肉・企業名言及・ネガ・曖昧 → AIが下書き → **俊雄さん承認キュー** → 1タップ送信。
- ⛔ 禁止：**生成文を無承認で他人に送らない**／**どら猫キャラでのリプライ応戦は全面禁止**（毒は4コマの中だけ。他者へのリプは運営トーン）／特定企業名をネガ断定で返さない。
- 荒らし・誹謗：無反応＋フラグ（必要なら hide）。

**炎上・通報プロトコル**
- トリガー：否定的引用/コメント5件以上／個人・企業から名指し抗議／「通報した」明示／メディア・インフルエンサー言及。
- 対応3分類：(沈黙)単発の悪口＝無反応／(静かに削除)絶対線・強度上限を自分が越えていた＝謝罪なしで削除＋記録／(謝罪)事実誤認・実在者を傷つけた＝**運営名義（どら猫を脱ぐ）**で短く訂正。
- **削除前に必ずスクショ保存**（証拠保全）。対応は lessons.md に記録。
- 時間基準：俊雄さん平日不在のため「気づいた最初のセッションで即時／ただし自動投稿は気づいた瞬間に停止」。

**自動投稿の安全装置（kill switch）**
- **4コマ画像は原則 自動スケジュール投稿**（毎日12:00・タスク `Subsuku_Threads_4koma_1200`・俊雄さん指示2026-06-07）。テキスト queue.json は20:00・強度3以下。
- 安全装置（kill-switch は"禁止"でなく"緊急停止"）：① reply-handler でコメント監視 → 批判/炎上は承認キュー、② 炎上時は `Disable-ScheduledTask -TaskName Subsuku_Threads_4koma_1200` で即停止。フォロワー増で炎上リスクが上がったら頻度/強度を再調整。
- 炎上を察知したら、まず Windows タスク（Threads自動投稿 `Subsuku_Threads_AutoPost_2000` 等）を停止してから対応する。
- リプライ自動送信（`reply-handler.mjs`）は環境変数 `THREADS_REPLY_AUTOSEND` で制御。**既定OFF**＝全件キュー行き。安全カテゴリ（テンプレFAQ）だけ ON にできる。

## 5. 決定：チャネルは Threads（2026-06-01 俊雄さん指定）

**告知の主戦場を Threads に確定。** 理由＝新規アカウントでも伸びやすい／画像投稿の抑制が緩い／テキスト主体で4コマキャプションと相性が良い／Instagram連携で初速がつきやすい。

### Threads 向けの最適化（X/noteと違う点）
- **1行目が命**：Threadsはタイムラインで1〜2行しか見えない。キャプションの「フック」を先頭に置く（例：`「来月から本気出す」って毎月言ってない…？🐱`）。
- **リンクはそのまま貼ってOK**：Threadsは本文中URLがクリック可能。ただし*リンク付き投稿はリーチがやや落ちる*ので、**画像＋短文＋URLは1行だけ**にして本文の主役は共感コピーにする。
- **ハッシュタグは1個だけ**（Threadsはトピックタグ1つ運用が基本）。例：`#サブスク解約`。X用の複数タグは使わない。
- **テキストだけの投稿も混ぜる**：4コマ画像の合間に「1行あるある＋問い」のテキスト投稿を挟むと反応が伸びやすい。
- **連投（スレッド）でファネル**：1投目＝4コマ画像＋共感、2投目（リプライ）＝`で、あなたのサブスクは？ 無料診断 → sabusuku.netlify.app/games`。リンクを2投目に分けると1投目のリーチを守れる。
