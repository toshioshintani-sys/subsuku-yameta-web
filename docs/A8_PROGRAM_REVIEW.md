## 核心の区別（これがグレードの分かれ目）
> **「情報として“載せる”」と「アフィリンクで“推す”」を分ける。**
- **推す**＝両論併記・置換ROI・SRE3フル（アフィの主役）
- **載せる**＝中立に存在を紹介（図鑑の網羅・SEO面）。アフィは任意/無しでも可
- **除外**＝サブスクの“次の動き”に当たらない真の主題外のみ（載せると図鑑のトピック一貫性が薄れ SEO/AdSense 評価を下げる）

## 実装ゲート（暴走防止）
1. **トラッキングURL・報酬額がCSVに無い** → A8の広告リンク作成画面で取得（俊雄さんのChromeで既ログインのセッションを使い、Claudeはパスワード入力せず生成のみ代行）。
2. **SRE3 ①置換性**：A/B は「○○をやめて置き換える」文脈＋ROI＋両論併記をセットに。C は情報掲載のため緩め。
3. **§5-D**：カーリース等 **報酬2,000円超えの“推し（A/B昇格）”は proposal-stress-test 必須**。
4. **§2-2 信頼最優先・BAE 7:3**：A（推し）は増やしすぎない。C（情報）で網羅、A は厳選。

## 推奨ロードマップ
1. **ABEMA(A)** を既存ABEMA/動画ページに「乗換先」両論併記で（低単価・即収益・最小リスク）。
2. **浄水型サーバー(A)** → **dicon/Dentaly(A)** → **知育玩具(A)**。
3. C 群は `/discover` 図鑑に**情報掲載**として薄く網羅（アフィ任意）。
4. カーリース等 B 高単価は stress-test を通してから A 昇格。
