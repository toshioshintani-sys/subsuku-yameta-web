## 運用ルール（craft 準拠・全投稿で厳守）
- **バイアス名は出さない**（「サンクコスト」等を本文に書かない。癖の“描写”で見せる）
- **感情語を使わない**（「不安」「もったいない」ではなく、その瞬間の行動を描く）
- **1行目がフック**（Threadsは1〜2行しか見えない。共感の刺さる一撃を先頭に）
- **リンクは本文に入れず、自分への返信（2投目）に置く**（1投目のリーチを守る）
- **ハッシュタグは1個だけ**
- **猫（🐱）が狂言回し**（既存4コマと世界観を統一）
- CTA先：`sabusuku.netlify.app/games`（診断ゲーム）/ `sabusuku.netlify.app/tracker`（棚卸し）

### 連投テンプレ（毎回この形）
```
[1投目] 画像 or テキスト本文（フック→共感→小さなオチ）  #タグ1個
   └[2投目=返信] で、あなたのは？ → sabusuku.netlify.app/games
```

## B. 4コマ画像投稿（脚本＋生成プロンプト＋キャプション・5本）

> 画像生成は ChatGPT（世界観OK）か Gemini（テキスト厳格）に下の脚本を貼るだけ。
> 既出の3本（kokuchi-plan.md §2）に加えて新規5本。

### 4コマ④「自動更新」（デフォルト効果）
```
① 女「無料体験、面白かったな」
② 画面の隅に小さく「※30日後に自動で月額に移行します」
③（無音で30日経過）通帳に、見覚えのある引き落とし
④ 猫が、契約時に“自動更新オフ”のチェックを先に外しておく
```
キャプション：`無料体験のあと、勝手に課金されてた経験ない？🐱 「何もしない」と続く設計に、こっちから先回り。`　タグ：`#サブスク`
返信：`自動更新サブスクの棚卸し → sabusuku.netlify.app/tracker`

### 4コマ⑤「全部見なきゃ」（プランニング誤謬）
```
① 男「このシリーズ全12話、週末で見終わる」
② （週末）3話で寝落ち
③ 「来週こそ」を8回くりかえし、配信終了のお知らせ
④ 猫「“全部見る前提”で課金、毎回ハズしてるよ」
```
キャプション：`「週末で見終わる」、何回ハズした？🐱 見る量を盛って課金しがちな人へ。`　タグ：`#節約`
返信：`続ける/やめるを30秒で → sabusuku.netlify.app/games`

```
① 店員「松9,800円・竹4,980円・梅1,980円です」
② 男（松は高い…梅は不安…）「じゃあ竹で」
③ ナレ「“竹”が選ばれるように、松は置かれている」
④ 猫「で、その竹の容量、半分も使ってないよね」
```

返信：`プラン別の年額を比較 → sabusuku.netlify.app/tracker`
