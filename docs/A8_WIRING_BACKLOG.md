いただいたCSVには**報酬額（成果報酬）の列がありません**。A8.netの正確な現行報酬額はプログラムごとに提携先ログイン後の管理画面でしか確認できないものが大半で、公開情報だけでは把握できません。

- A8.net公式の公開ランキングページ（`support.a8.net/as/HintOfProgram/ranking/*`）を実際にfetchして、掲載されている実額を確認できたものは「確認済」と明記

## 除外したプログラム（判断理由）

- **転職・IT求人系7件**（TechGo、フリーランスボード、IT求人ナビ フリーランス、R4CAREER、社内SE転職ナビ、タネックス、転職AGENT Navi）→ サブスクやめたと無関係。別サイト「Career Option Audit」向け
- **ASP自体の成果反映用・メディア募集プログラム5件**（楽天アフィリエイト、Amazon.co.jp成果反映用、A8.net成果反映用、A8.netメディア会員募集、楽天市場アフィリエイト、A8セルフバック）→ 読者向け商材ではなく自社の集計インフラ
- **動画教材エディター養成コース（50,000円・A8公式確認済の最高単価級）** → 「歩合報酬あり」の紹介制スクールでMLM的な構造の懸念があり、報酬額の高さだけで採用するのはリスクと判断。除外
- **narasu（楽曲配信）** → リスナー向けサブスクではなくアーティストの自己配信ツール。既存の音楽サブスク（Spotify等）とは利用者層が異なる
- **KIWI Spark（電子タバコ）** → サブスク性がなく単発の「特別価格キャンペーン」商品。テーマ外
- **2012〜2014年提携の古い2プログラム**（オンラインレンタル、一眼レフ講座）→ 他の78件と比べて提携日が突出して古く、稼働状況が不明。優先度から除外し、必要なら個別に生存確認を推奨
- **wifi群（ブリッジWiFi、WiFi東京プリペイド）** → 旅行者向け短期利用商材で、既存67サービスの解約・乗換文脈とは噛み合わせが弱い。単価も低めと推定されるため今回は見送り
