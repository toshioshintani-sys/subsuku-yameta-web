# A8 で「サブスクやめた」用の追跡URLを取得する手順

## 現状（2026-05-23 時点）

- ✅ A8 で 42 件のプログラム提携承認済み
- ❌ ただし提携審査は **「ライフオラクル」サイト** で通っているもの
- ❌ 「サブスクやめた」（sabusuku.netlify.app）は **まだA8にサイト登録されていない**
- ⚠️ そのまま「ライフオラクル」用URLを「サブスクやめた」に貼ると**規約違反のリスクあり**

## 正しい3ステップ（俊雄さんお願いします）

### Step 1：A8 に「サブスクやめた」をサイト追加（5分）

1. https://media-console.a8.net/registration-information/site にアクセス
2. 再認証画面が出たらログインID・パスワード入力
3. **「新しいサイトを登録」** をクリック
4. 入力内容：
   - サイト名：**サブスクやめた**
   - サイトURL：**https://sabusuku.netlify.app**
   - サイトカテゴリ：**ライフスタイル / その他**
   - 月間PV：**1000未満**（始まったばかりなので）
   - サイト紹介文（例）：
     ```
     サブスクリプションサービスの解約導線を集約したインデックスサイト。
     59以上のサブスクの解約ページに1クリックでジャンプでき、引き止め
     画面の対策まで掲載。サブスク棚卸しダッシュボードや、生活を変える
     サブスクの中立的な紹介もあわせて提供。
     ```
5. 「確認画面へ」→「登録」で完了

### Step 2：8 案件に「サブスクやめた」での追加申請（10〜15分）

discover に載せた8案件について、「サブスクやめた」サイトでの掲載を追加申請する：

**操作手順**（1案件ずつ）：

1. A8 トップで「プログラム検索」→ 上記キーワードで検索
2. 該当プログラムの「**詳細を見る**」または「**提携申請**」ボタンを開く
3. 申請画面で**「掲載サイト」を「サブスクやめた」に切り替え**
4. 「提携申請する」をクリック

すでに「ライフオラクル」で提携済みのプログラムも、**別サイトでは別途審査が必要**です。

### Step 3：承認後（3〜10日後）

承認メールが届いたら：

1. https://media-console.a8.net/program/list/partnered で「サブスクやめた」用の参加プログラムを確認
2. 各プログラムの「**広告リンク作成**」→「**テキスト**」を選択
3. 表示された追跡 URL（`https://px.a8.net/svt/ejp?a8mat=...`）をコピー
4. このリポジトリの `src/data/discover.js` を編集

```js
// 例：HitoHana の場合
{
  name: 'HitoHana（ひとはな）',
  // ...
  affiliateUrl: 'https://px.a8.net/svt/ejp?a8mat=...',  // ← ここに貼る
},
```

5. 8件すべて埋まったら、git commit / push → Netlify 自動デプロイ → **実収益化開始**

## 既存「ライフオラクル」掲載分は？

「ライフオラクル」（life-oracle.jp）でも、これらの案件は提携済みなので、向こうのサイトの方でも自由に貼り付けOK。
ただし `ライフオラクル/` 配下とは別プロジェクトなので、貼るかどうかは別途判断。

## なぜこの手順が必要か

A8 の規約：
- 1メディアID（俊雄さんのアカウント）で複数サイトの登録は可能
- ただし提携審査は **サイト単位** で行われる
- A サイトで提携承認されたプログラムを B サイトで掲載するのは **広告主に黙って別サイトで使うこと** になり、規約違反
- 発覚すると、最悪の場合 A8 アカウント自体が停止される

正規ルートで進めれば、長期的に安全に収益化できます。
