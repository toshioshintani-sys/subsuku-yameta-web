## 2026-05-26 ★★★ 屋台ゲーム景品（やめたつもり貯金ゲームの拡張）

### 俊雄さん発言

> 「祭りの屋台みたいのゲームの景品が欲しいですね。情報とか、割引券とかかもしれませんがちょっと嬉しいもの。」

### コンセプト

ゲームのスコアに応じて段階的に「ちょっと嬉しい」景品をアンロック。
お金的価値ではなく、**「お祭りの屋台で当てた」 感** が肝。

### 景品候補（5案・段階アンロック）

| スコア帯 | 景品 | 実装難度 | 補足 |
|---|---|---|---|
| ¥1,500+ | 行動経済学TIPSカード（バイアス解説1枚・ランダム） | 低 | JSONデータ＋モーダル表示 |
| ¥3,000+ | 「次の動き」テンプレートPDF（固定費棚卸し用A4） | 中 | PDF生成 or 静的ファイル配布 |
| ¥5,000+ | 隠しブログ記事へのアクセス（限定URL） | 低 | 既存blog機能で `unlisted: true` フラグ |
| ¥8,000+ | やめて買う 全25品の早見表PDF | 中 | カテゴリ・価格・選び方の要約 |
| ¥10,000+ | 達成記念バッジ（SVG・SNSシェア可） | 低 | SVG動的生成＋シェアリンク |

### 設計上の注意

- 景品はアフィリエイト誘導に絶対使わない（純粋な"おまけ"）
- 割引券系は ASP との交渉が必要 → Phase 2 以降
- 行動経済学TIPS は **ライフオラクルとの哲学的接点** にもなる（読者が「もっと知りたい」と思ったら自然に橋渡し）

### Phase

Phase 4（2026-08-16 〜 09-15）/news 機能と同時期に検討。
ただし「TIPSカード + 隠しブログ記事」だけなら Phase 2 末で先行リリース可能。

## 2026-05-26 ★★★ YES/NO 性格診断（3層判定）

### 俊雄さん発言

> 「簡単のYESNO性格診断もあるといいかも。」

### コンセプト

5〜7問のYES/NOで読者を BAE 3層モデル（A/B/C層）に振り分け、
最適な次のページに誘導する軽量診断。

### 質問案（7問・実装時に5問に絞っても可）

```
Q1. 今あるサブスク、毎月見直していますか？           Y/N
Q2. 「もっと良いサービスがあれば乗り換えたい」と思う Y/N
Q3. 月に2,000円使うなら "買い切り" 派？             Y/N
Q4. 新しいサービスを試すのが好きですか？             Y/N
Q5. 「使ってないけど解約面倒」が常態化している       Y/N
Q6. 浮いたお金で何か買うのが楽しい                   Y/N
Q7. 月額が「気づいたら増えてる」状態にある           Y/N
```

### 判定ロジック（仮）

| パターン | タイプ | 誘導先 |
|---|---|---|
| Q1=N, Q5=Y, Q7=Y が多い | **A. 整理派**（離脱型）| `/tracker` + 「今月の固定費を可視化」 |
| Q2=Y, Q4=Y が多い | **B. 探検派**（乗換型）| `/discover` + 「他のサブスクと比較」 |
| Q3=Y, Q6=Y が多い | **C. 道具派**（整理＋買い切り型）| `/yamete-kau` + 「買い切りで揃える」 |

### BAE 準拠の表現ルール

- 結果ページで「あなたは○○タイプ。××サブスクがおすすめ」と決め打ちしない（禁則）
- 「これは一つの見方です」「逆の選択も正解」とフッターに添える
- 診断結果でアフィリエイト商品を直接プッシュしない（誘導は3層ページへ）
- ライフオラクル（ユング × 行動経済学）の世界観に寄せすぎない（実利特化を守る）

### 配置

- `/quiz` ルート新設（軽量・1ページ）
- HomePage の「使い方ガイド」セクション内に小さなリンクで誘導
- Tracker や Discover からも誘導可能

### Phase

Phase 2 末（2026-07-15）が現実的。3層モデル誘導の最後の入口として完成度を上げる。
