## §0. 一度だけ（前提）

1. **ライフオラクルとは別の note アカウントを作る**（別メール）。プロフィール：
   - 名前：`サブスクやめた`
   - 自己紹介：「サブスクの解約・乗り換え・買い切りを、煽らず両論併記で。月額の固定費から動き出したいあなたへ。」
   - リンク：`https://sabusuku-yameta.com`
   - ※アカウント作成・ログインは俊雄さんの原子操作（私は代行不可）

2. **SEOメモ（note特有・1回読めばOK）**：noteはcanonical設定が無いので、
   - 各原稿の**冒頭にある「初出リンク」を必ず残す**（既に原稿に入っている・消さない）
   - 可能なら**元記事がGoogleにインデックスされてから**転載するとより安全。**ただしW杯など旬物は即出し優先**（鮮度の価値が勝つ）

---

## §1. 1記事の投稿手順（毎回これだけ）

1. note で **新規記事を作成**
2. 下表の**タイトル**を貼る
3. 対応する `docs/syndication/<ファイル>.md` の**中身を全部コピペ**（冒頭の初出リンク〜末尾の関連リンクまで丸ごと）
4. 見出し（##）はnoteが自動で見出し化。画像は任意（無くても可）
5. **公開**

> それだけ。リンクは既に `utm_source=note` 入りなので、GA4で流入を計測できます。

## §3. ペース & 計測

- **週1の固定枠**を1つ決める（note は予測可能性＝習慣化と相性が良い）。各投稿はコピペで約5分。
- **初速を取りたいなら最初の2〜3週だけ2〜3本/週**にして、効くか早く見る→以降は週1維持。
- **計測**：投稿1〜2週後、GA4（プロパティ538470329）→ 集客 > ソース/チャネルで **`note / referral`（または social）** を確認。`utm_campaign` 別にどの記事が送客したか分かる→伸びるテーマに寄せる。
- **判定の目安**：2〜3週で note 経由の流入が「ゼロではなく増えている」なら継続・加速。全く動かなければ、タイトルの付け方（noteの検索/おすすめに乗る言い回し）を見直す。
