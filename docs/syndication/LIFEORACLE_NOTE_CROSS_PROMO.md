## 0. 何を・どこに・誰が

- **対象**：**今日（2026-06-27）以降に投稿する、ライフオラクルnoteの全記事**。過去記事は遡及しない（試し＝新規分だけで効きを見る）。
- **位置**：記事の**最下段**（本文末尾・関連リンクの後）。冒頭ではない。
  - 理由：ライフオラクルとサブスクやめたは**別ブランド**（CLAUDE.md §9）。冒頭広告は読者体験と信頼（＝収益の源泉）を削り、noteのプロモ判定にも触れうる。**読み終えた人への"おまけの一言"**なら、別ブランド間でも信頼を壊さず効く。
- **誰が**：**Claudeが投稿時に自動付与**。note投稿は API（`NOTE_SESSION_TOKEN` / `scripts/note/post-note.mjs` と同方式）で実行しており、本文(free_body)末尾へ下記ブロックを足してから確定(PUT)する。**俊雄さんの原子操作はnoteアカウントのログイン/トークン供給のみ**。
- **トーン**：当事者視点・煽らない・両論併記の匂い（CLAUDE.md §2-2）。広告バナーにしない。書き手の一言にする。

## 2. 差し込みの実装（結線位置）

- **結線はライフオラクル側の投稿フロー**（`Claude_work` 配下・別プロジェクト＝§9別ブランド・本リポジトリのスコープ外）。本書の最下段ブロックを**唯一の正**として参照し、`free_body` 末尾（関連リンクの後）へ追記してから note の確定(PUT)を呼ぶ。
- 結線の最小形（このリポジトリの `scripts/note/post-note.mjs` と同じmarkdown→HTML方式の場合）：記事markdownの末尾に §1 のブロックを連結 → 既存の `markdownToNoteHtml(md)` に通すだけ（`<hr>`＋段落＋アンカーに変換される）。専用関数は不要。
- **テーマ判定**：記事のタグ/タイトルに「お金・固定費・節約・家計・見直し・手放す・ミニマル」が含まれれば B、明確に無関係（占い・スピリチュアル等）なら C、それ以外は A。

## 3. 計測（GA4で「ライフオラクルnote経由」を分離）

- UTM＝`utm_source=note-lifeoracle / utm_medium=referral / utm_campaign=cross-promo`。
- **サブスクやめた名義note転載（`utm_source=note`）とは別ソース**にしてあるので、GA4（プロパティ538470329）→ 集客 > ソース/チャネルで `note-lifeoracle` を独立して読める。
- **見る指標**：①`note-lifeoracle` セッション数 ②そこからの回遊（解約導線/図鑑への到達）③`affiliate_click` の発火。

- **2〜3週**で `note-lifeoracle` 経由が「ゼロでなく増えている」→ 継続・加速（バリエーション最適化／本文中の自然な関連リンクも検討）。
