# 他のAIへのネタ依頼文（コピーして貼る）

共有ページ（Artifact）と同じ文面。返ってきたネタは docs/THREADS_NETA_BOOK_2026-10.md に追記し、俊雄さんが判定する。

```
あなたは、お笑いコンビの台本を書く放送作家です。SNS（Threads）に投稿する、文字だけの短い笑いのネタを、30本書いてください。

【目的】
Threadsで1本でも多く「おもしろい」と言われ、見た人が「この人なんだろう」とプロフィールを見に来る状態を作りたい。まずは笑ってもらうことだけが目的です。ネタの内容は自由で、商品やサービスの宣伝は一切入れません。

【形式】
・本文は日本語で、最大でも120文字。短いほどよい。
・文字だけ。写真・絵文字・ハッシュタグは使わない。
・1行目で状況が浮かび、最後の一言で転ぶ。

【今までの調査でわかっていること】
・Threadsの日本語のバズ投稿500件を分類した。強かったのは、子ども・家族のひとこと、会話の再現、勘違いが解ける瞬間、親切・ほっこり、理不尽への一言。
・「落ちを言うのが、子どもや相手など他人」の型が強い。場面が目に浮かぶ。

【すでに「面白くない」と判定された4本（この型は避ける）】
・「夜分遅くに失礼します」と送ったら、送信時刻が昼の12時だった。夜分は、私の心の中。
・無料体験を始めた日の私は、終わる日の私を完全に信用していた。
・計画表は完璧。計画表を作った自分は、もうそこにいなかった。
・「確信犯」の意味を、新人のころ堂々と間違えて説明した。いちばん確信を持って間違えた。
→ 共通点は「語り手が、気の利いた一文を自分で言って落とす」型。言葉の技で、場面が浮かびません。

【まだ判定していない下書き（参考。これより面白いものを書いてほしい）】
・息子（5歳）が「ぼく、ひみつ守れるよ」と言うので、秘密を教えた。1分後、家族全員が知っていた。
・友達「全然待ってないよ」　その人の飲み物は、もう2杯目だった。
・母「ちゃんと食べてる？」私「食べてる」母「何を」私「…カップ麺」母「それは食べてるって言わないの」

【日本の読者に向けた笑いにすること（アメリカンジョークは日本では受けません）】
・英語圏のジョークの型は避ける。短い小話でオチの一撃で笑わせる型、皮肉・風刺・政治や時事ネタ、毒舌、下ネタ、大げさな自慢、「Why did…」のような問答、英語の言葉遊びを直訳したもの。翻訳調・海外ジョーク調の文は不可。
・日本のThreadsで受けるのは、「あるある」への共感、ツッコミが入る前提の小さなボケ、控えめな自虐、ほっこり、場面のズレ。オチを説明せず、余韻で終わる。
・日本の生活の細部を使う（敬語・あいさつ・おじぎ、満員電車、宅配、PTA、親との電話など）。ただし、固有の会社名や商品名は出さない。
・文は自然な話し言葉の日本語で。会話は「」で書く。オチを「〜ってわけさ」「やれやれ」のようなキザな言い回しにしない。

【守ること】
・会社名・商品名・サービス名・実在の人物名・金額の数字を出さない。
・笑う相手は「自分」と「仕組み・状況」だけ。人を見下す・属性をいじる・悲しい出来事を軽く扱うネタは不可。
・「いいね」「返信」「シェア」を求めない。説教や教訓で終わらない。
・日常の小話は創作として書いてよい（実話と言い張らない）。

【書き方の指定】
次の5つの型を6本ずつ、合計30本。
A. 子どもや家族の一言で転ぶ（会話の再現）
B. 勘違い・言い間違いが解ける瞬間（自分の失敗の打ち明け）
C. 理不尽・あるあるへの一言（相手や状況のズレ）
D. ほっこり・親切（最後にくすっとする）
E. 返信で参加できるお題（1行で答えられて、知識がいらないもの。お題とその答えの例を1つ）

【出力形式】
1本ごとに次の3行で。
番号・型：（A〜E）
本文：（120文字以内）
転ぶ場所：（どの言葉で落ちるか、一言）

最後に、30本の中で「自分ならこれを最初に出す」上位5本と、その理由を書いてください。自信のないネタには「弱い」と正直に書いてください。無理に面白いと言わなくてかまいません。
```

# 第2版（2026-10-18）：決まりを外して各AIの独自性を引き出す依頼文

第1版（型×本数×120字など）で3社24本の案が出たが、どれも「しっくり来なかった」。原因の仮説＝指示が細かすぎて、AIが定番に収束した。第2版は型・長さ・本数の縛りを外し、定番の回避と「あえて逆らった1本」を求める。

```
あなたは、日本のお笑いを深く知っている作家です。日本語のSNS（Threads）に、文字だけで投稿して、読んだ人が思わず笑う、誰かに見せたくなる、「この人、何者？」とプロフィールを見に来る。そんな投稿のネタを書いてください。

型・長さ・形式の決まりはありません。あなた自身が「これは本当に面白い」と思うものだけを書いてください。

【目的】
Threadsで笑ってもらうことだけが目的です。商品やサービスの宣伝・教訓・まとめは不要です。

【自由にしていいこと】
・型は自由。会話、一人語り、短いコント、お題（返信で参加できるもの）、つぶやき、ミニストーリー、箇条書き、何でも。
・長さは自由。ただしThreadsの上限（500字）まで。長くても、短くてもよい。
・テーマも自由。家族、仕事、街、動物、ネット、季節、シュール、言葉、何でも。
・本数も自由。質が落ちるなら少なくてよい。目安は10〜20本。

【してほしいこと】
・ほかのAIが書きそうな定番は避けてください。たとえば、歯医者で手を挙げる、子どもが秘密をばらす、カップ麺はご飯と言わない、傘に入れてくれた人が実は自分も傘がない、満員電車で「降ります」。これらはすでに何度も出ていて、既視感があります。
・きれいにまとめたり、いい話に落としたり、無難にしたりしない。あなたの笑いの感覚を出してください。
・「面白い」と言い切れないものは書かない。

【参考（縛りではありません）】
・日本のThreadsのバズ投稿500件を調べると、子ども・家族のひとこと、会話の再現、勘違いが解ける瞬間、親切・ほっこり、理不尽への一言が多く見つかりました。これに従わなくて構いません。
・次のような「語り手が気の利いた一文を自分で言って落とす」型は、読んだ人に「面白くない」と言われました。
　「夜分遅くに失礼します」と送ったら、送信時刻が昼の12時だった。夜分は、私の心の中。
　計画表は完璧。計画表を作った自分は、もうそこにいなかった。
・アメリカンジョーク（短い小話の一撃、皮肉・風刺、毒舌、下ネタ、直訳調）は日本では受けにくいです。日本語の日常の感覚で書いてください。

【最低限の安全線（これだけは守る）】
・会社名・商品名・サービス名・実在の人物名を出さない。金額の数字を出さない。
・人を見下す、属性（性別・年齢・職業・出身など）をいじる、悲しい出来事を軽く扱うネタは書かない。
・「いいね」「返信」「シェア」を求めない。
・創作として書いてよい（実話と言い張らなくてよい）。

【出力】
形式は自由。ネタの本文を書き、各ネタに一言だけ「どこを狙ったか」を添えてください。最後に、次の2つを教えてください。
1. 自分のなかで一番自信のある1本とその理由
2. 世の中の「受ける型」にあえて逆らって書いたものがあれば、それはどれか
```
