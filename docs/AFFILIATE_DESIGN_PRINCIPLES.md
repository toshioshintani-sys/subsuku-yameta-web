# アフィリエイト設計原則（BAE：Behavioral Affiliate Engine）

> このドキュメントは「サブスクやめた」サイト内でアフィリエイトリンクを配置する際の**実装規則**である。
> 思想・社会運動の話ではなく、コードとデザインを判断するための具体的なルール集。
> 迷ったらここに戻る。

---

## なぜこの原則が必要か（1分で）

「サブスクやめた」は **「やめさせてくれるサイト」** として信頼を獲得することが最優先。
アフィリエイトはその信頼の上に立てる二次収益。順序を間違えると、両方を失う。

**目指す状態：**
- 競合サイトが「ランキング！おすすめ！」と叫ぶ中、
- 当サイトは静かな確信で読者を行動に至らせる。
- 結果として CTR は競合より高く、なおかつ「下品」と評価されない。

これを行動経済学の言葉で実装したのが BAE（Behavioral Affiliate Engine）。

---

## 絶対原則（3つの不可侵ルール）

### 原則 A：7:3 ルール
- ページ内の文量比率：教育コンテンツ 7 / 代替案提示 3
- 比率が逆転したらリファクタ対象

### 原則 B：解約導線 > アフィリエイト の絶対序列
- 解約ページへのリンク（CTA）は、ページ内のどのアフィリエイトリンクより**ビジュアル的に必ず強い**
- カラー、サイズ、配置、すべて解約が主役
- 違反例：「解約方法」リンクが地味、隣の「楽天で探す」がカラーボタン → 即修正

### 原則 C：両論併記
- 紹介するすべてのサービスにデメリットを明記する
- デメリットがないと感じても、最低1つは書く（信頼性の証）
- 例：「HitoHana の弱点：玄関の留守時に受け取れない問題」

この3原則を破る実装はマージしない。

## 行動経済学レイヤー（実装テクニック）

### 1. デフォルト効果
**実装：** サービスページ下部に「卒業→入学」ブロックを**控えめに**常設。
押し付けない、でも視界から外さない。ユーザーの脳が勝手に処理を始める。

```html
<section class="post-cancel-options" aria-label="やめた後の選択肢">
  <h2>もし続ける選択肢を探すなら</h2>
  ...
</section>
```

### 2. 損失回避
**実装：** 各サービスページに「年額試算」ブロックを必ず置く。
- 「現在の月額 3,000円 × 12 = **年36,000円**を払い続けています」
- アフィリエイト側：「都度購入なら年間6,000円。**30,000円の解放**」

### 3. アンカリング
**実装：** 月額の高いオプションを上に、安い代替を下に並べる。
脳が自動で差額を計算する。

### 4. 社会的証明
**実装：** GA4 連動の閲覧数を表示。
- 「同じく HitoHana のページを **1,234人** が読んでいます」
- 数値は実数。盛らない。ゼロのときは出さない。

### 5. 選択肢の逆説の解消
**実装：** 1ジャンルあたり代替案は**厳選3つだけ**。
4つ以上にしない。「100案件から厳選」感が品位と説得力を両立。

### 6. フレーミング
**禁止語と推奨語：**
| 禁止 | 推奨 |
|---|---|
| アフィリエイト広告 | 次に検討したい選択肢 |
| おすすめ・ベスト・No.1 | 特徴と料金 |
| ランキング | 比較表（順位なし） |
| 節約術 | 自分の時間とお金を取り戻す |
| ★★★★★ | デメリット併記の説明文 |

### 7. ピーク・エンドの法則（最重要）
**実装：** 解約ガイドを読み終えた**ページ末尾**を「ピーク」とみなす。
そこに代替案を**1個だけ**置く。複数置くと効果が散る。

### 8. パーソナライズ
**実装：** `/tracker` で登録されたサブスクから、自動的に関連する代替案を出す。
例：Netflix 登録者 → Amazon Prime Video の選択肢を提示。

### 9. ストーリーテリング
**実装：** 「卒業→入学」ブログシリーズでは、俊雄さんの**一次体験**を必ず1段落入れる。
商品レビューではなく、心理プロセスを書く。
- ❌「HitoHana は配送が遅い」
- ✅「私は3回目の配送で『花瓶を捨てた』と気づき、定期便を解約した」

### 10. シグナル非対称性（デザイン）
**実装規則：**

| 要素 | スタイル |
|---|---|
| 解約ボタン | カラー塗りつぶし・大型・ファーストビュー上部 |
| アフィリエイトリンク | 薄いグレー枠・テキストリンク中心・ページ末尾 |
| バナー画像 | 使わない |
| 派手な背景色 | 使わない |
| 「PR」ラベル | アフィリエイトブロック隅に小さく必須（景表法対応） |

CSSクラス命名規則：
- `.cancel-cta` — 解約導線（メインカラー）
- `.alternative-option` — アフィリエイト代替案（サブカラー・控えめ）
- `.pr-label` — 「PR」表示（極小フォント）

## 禁止事項（コードレビューで必ず弾く）

- ❌ ランキング表（1位、2位…）
- ❌ ★スコア、おすすめ度
- ❌ 「絶対おすすめ」「迷ったらこれ」「No.1」「最強」などの煽り
- ❌ アフィリエイトバナー画像
- ❌ ポップアップ広告
- ❌ 隠しリンク（テキスト色 = 背景色 等）
- ❌ ステマ（PR ラベルなしでアフィリエイトリンクを記事に混ぜる）
- ❌ デメリット記載なしのサービス紹介
- ❌ 解約ボタンよりアフィリエイトボタンが目立つレイアウト

## 透明性ルール

### 収益開示ページ
- `/disclosure` ルートで「収益開示」ページを設置
- フッターに常時リンク
- 内容：
  - 「当サイトは Amazon アソシエイト・A8・もしも・楽天アフィリエイト等のプログラムを利用しています」
  - 「掲載順位は提携の有無や報酬で決まりません」
  - 「読者の利益に反する商品は紹介しません」

### PR ラベル位置
- すべてのアフィリエイトブロックの右上隅に `<span class="pr-label">PR</span>` を設置
- fontSize: 10-11px、color: gray
- aria-label でスクリーンリーダーにも認識させる

## ServicePage の標準構造（テンプレート）

```
[ServicePage]
├── ヒーロー：サービス名・月額・公式リンク（中立的）
├── 解約方法（メインコンテンツ・7割）
│   ├── 解約手順（ステップごと）
│   ├── 引き止め画面の対策
│   └── 【解約ページへ】← 最大の CTA（cancel-cta クラス）
├── デメリット併記の説明（教育コンテンツの一部）
├── FAQ
├── 損失可視化ブロック（行動経済学レイヤー2）
└── やめた後の選択肢（記事末尾・ピーク位置・3割）
    ├── 厳選3つの代替案（alternative-option クラス）
    ├── PRラベル
    └── 「もし都度購入したい場合」インラインリンク（楽天/Amazon）
```

## discover.js の標準構造（テンプレート）

```
[DiscoverGenrePage]
├── ジャンル説明（教育コンテンツ・5割）
│   ├── このジャンルの市場概観
│   ├── サブスクvs買い切りの判断軸
│   └── 「やめた人がよく感じる気づき」
├── 厳選3サービスの比較表（順位なし・特徴並列）
│   ├── 各サービスにメリット・デメリット必須
│   └── 公式リンク（alternative-option クラス）
└── 「やめたくなったら」セクション（解約ガイドへの導線）
```

## 計測ルール（GA4）

すべてのアフィリエイトクリックを GA4 のカスタムイベントで計測：

```javascript
gtag('event', 'affiliate_click', {
  asp: 'a8' | 'moshimo' | 'amazon' | 'rakuten',
  service: 'hitohana',
  placement: 'service_page_bottom' | 'discover_genre' | 'blog_inline',
  position: 1 | 2 | 3,  // 厳選3つの順番
});
```

これにより：
- どの ASP の CTR が高いか
- どの placement が効くか
- A/Bテストの結果がデータで判断できる

## A/Bテスト計画（Phase 1 後）

仮説：「煽り型より静かな確信のほうが CTR が高い」

実装後1ヶ月で以下を比較：
- バリアント A：BAE 原則準拠（このドキュメント）
- バリアント B：競合風煽り型（「絶対おすすめ！」「ランキング1位」）

判断基準：
- CTR、CVR、滞在時間、直帰率
- BAE が勝てば、本ドキュメントを正典として固定
- 敗れたら本ドキュメントを修正、ただし禁止事項（ランキング・★スコア）は維持
