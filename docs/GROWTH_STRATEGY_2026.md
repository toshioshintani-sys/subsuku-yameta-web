## 0. 残酷な現実認識（ここから逃げない）

- 自社送客（サブスクやめたworld=0／ライフオラクル=100）は**誤差**。集客の答えにならない。
- 「意味のある利益（月数十万円〜）」に必要な規模：**月 数十万〜100万 PV**（AdSense主体）＋**高単価成約の薄い層**（アフィリエイト）。

## 1. 野望の再定義（What we are becoming）

> **サブスクやめた＝日本の「解約・乗換・買い切り」意思決定インフラ。そしてAI検索が引用する一次データ源。**

ブログではない。**「このサブスク、続ける／やめる／乗り換える／買い切る、どれが得か」を即答するデータベース**。人間にもAIにも引かれる存在になる。この水準なら収益は多層化する（広告／アフィリ／高単価物販／B層乗換ASP／データ提携）。

## 2. 成長エンジン（記事ではなく、仕組み）

### E1. プログラマティックSEO（桁を変える本命）
解約は「サービス × 意図」の掛け算。`[サービス]解約方法 / 違約金 / 乗換先 / 買い切り代替 / 解約できない理由 / アプリ内課金解約 / 電話番号 / タイミング`…。**数百サービス × 数意図 ＝ 数千ページ**を、**実データで**構造生成する。
- 既存の services.js（構造化データ）を資産に、意図別ページをテンプレ生成。
- 鉄則：**薄いAI量産は禁止**（Googleが罰する）。各ページに固有の実価値（実手順・実違約金・実代替）を持たせる。私はこれを「品質を保ったまま大量に」作れる。新規ドメインでも**超ロングテールは勝てる**。

### E2. AI検索引用の支配（先行者ガラ空き・最重要の新分配）
ChatGPT/Gemini/Perplexity は「〇〇 解約方法」に答えるとき**情報源を引用**する。最も構造化・正確・網羅・更新された解約DBになれば、**AIが自動でサブスクやめたを引く**＝オーディエンス・グラフ不要の分配。
- 施策：schema markup（HowTo/FAQ/Breadcrumb）、機械可読な手順、定期更新、引用されやすい簡潔な定義文。
- データ（研究済）：AI経由はCV率14〜17%（通常検索2.8%の5倍超）。競合はまだ最適化していない。

### E3. ツール／計算機（集客＋"リスト獲得"の二刀流）
記事は遅い。**ツールは拡散・被リンク・埋め込み・ランクする**。
- 既存 /tracker を10倍化＋共有可能に。
- 「サブスク年額 損失診断」「サブスク vs 買い切り 損益分岐計算機」「解約し忘れ検出」「値上げ・改悪アラート」。
- **ツールでメール/LINEを獲得**＝下のE4へ直結。

### E4. オウンドリスト（LINE公式／メール）＝一回流入を反復資産に
最大の欠落＝**全トラフィックが使い捨て**（来て、去る）。リストがあれば一回の集客が反復配信になる。日本は**LINE公式アカウント**が桁違いに強い。
- フック：tracker・「サブスク見直しメール講座」・「値上げ／改悪アラート通知」。
- これが**アルゴリズムから audience を借りる罠から抜ける唯一の道**。owned が複利する。

### E5. ニュースジャック（値上げ・改悪 速報）＝即効バースト
サブスクは常に値上げ・改悪する。各イベントで解約検索が急騰する。**「〇〇値上げ → 解約方法 → 代替」を最速で出す**と、Google Discover・ニュース・SNSのバーストを獲れる。/news を「速報マシン」として再定義。反復的・高即効。

### E6. YouTube／Shorts（第二の検索エンジン）
解約手順の画面録画は**恒久・検索ベース・新規アカに比較的優しい**。各動画＝恒久流入＋サイト送客。制作コスト（俊雄さんの時間）は要るが、Shortsはテンプレ量産可。

### E7. 有料獲得（"心をゆさぶる"が、嘘はつかない版）
**AdSense目的の広告出稿はほぼ赤字**（RPM ≪ CPC）。撒くな。
**ただし高単価成約ページ限定なら、有料は無限スケールのダイヤルになる。**
- 例：家庭用脱毛器 1件¥1,500、B層乗換ASP ¥1,000〜1万/成約。
- **1成約の価値 ＞ 獲得単価（CPA）** が証明できれば、**¥を入れるほど利益が出る**＝即効性＋青天井。
- 手順：①高単価オファーを確保 → ②勝つLPを1枚作る → ③少額・計測付きでCPAを測る → ④損益分岐を割ったら増額。
- **これが「広告で即効」の正体。広告は起点ではなく"増幅器"。**前提（高単価オファー＋LP）を先に建てる。

## 3. 経済性（正直な数字・概算）

| 指標 | 概算 |
|---|---|
| AdSense RPM（JP・解約/家計系） | 約 ¥300〜800 / 1,000PV |
| 月10万PV | AdSense ¥3〜8万 ＋ アフィリ |
| 月100万PV | AdSense ¥30〜80万 ＋ アフィリ（ここが"意味のある利益"の入口） |
| 高単価アフィリ | 脱毛器¥1,500・B層ASP¥1k〜1万 ×成約数。少数でも効く |
| 有料の損益分岐 | CPA ＜ 1成約報酬 なら無限スケール可 |

**規模目標（野望ベース）**
- 〜6ヶ月：実データの構造化ページ 数百〜千＋ツール5〜10＋owned リスト立上げ → **月1〜5万PV／初収益 ¥1〜5万**
- 〜12ヶ月：AI引用獲得＋ニュースジャック定着＋高単価アフィリ engine → **月10〜30万PV／¥10〜30万**
- 〜18ヶ月：カテゴリ首位＋有料増幅＋多層収益 → **月数十万〜／"事業"化**

## 4. 不可侵（野望でも捨てない）
