### SSG（プリレンダ）対応 — AdSense「有用性の低いコンテンツ」対策
- `scripts/prerender.mjs` 導入：`vite build` 後に `vite preview` + Puppeteer で全ルートを実描画し、各 `dist/<route>/index.html` に本文HTMLを焼き込む
- ビルドコマンドを `vite build && node scripts/prerender.mjs` に変更（`build:nossg` も残置）
- プリレンダ中は AdSense / GA / GTM の読込をブロック（ポリシー「自動生成ツールによる表示の禁止」順守＋GA汚染防止）
- 結果：`dist/index.html` 約80KB・ブログ記事 約14KB と本文がHTMLに焼き込み済み（CSR空っぽ問題を解消）

### バイアス判断ゲーム量産基盤 — `/games`
- 汎用エンジン `src/components/BiasGame.jsx`（データ駆動・1バイアス=1オブジェクト）
- データ `src/data/biasGames.js` に **3本収録**：
  1. `sunk-cost` サンクコスト「ここまで払ったし…でやめられない」
  2. `status-quo` 現状維持バイアス「手続きが面倒でつい続ける」
  3. `loss-aversion` 損失回避「今の特典を失うと思うとやめられない」
- ページ：`GamesPage.jsx`（一覧）＋ `GameDetailPage.jsx`（`/games/:id`）
- 設計原則（lessons.md 2026-05-31）：バイアス名より「癖の説明」を主役に／各ゲームに必ず「やめるが正解じゃない」シナリオを1つ入れBAE原則（判断主権を読者に）を遵守
- 今後の量産：`biasGames.js` にオブジェクトを足すだけで第4本以降を追加可能
