# 制作ノート（Codex から俊雄さんへ）

## コンセプト

v3 で確定したキリさんを主役にして、「サブスクの紐が静かに切れ、右側の広い空へほどけていく瞬間」を描きました。頭部は正面チョキ型はさみのまま、V字刃・X字ピボット・2つの持ち手リングを全バリエーションで固定しています。旧横向きはさみ頭は使っていません。

紐はテラコッタで、契約カードはロゴや社名を持たない抽象カードにしました。お金や勝利演出ではなく、余白・地平線・朝/夜の空気で「これで少し軽くなった」という解放感を伝える設計です。

## 構図の意図

横長版はキリさんを左寄せに置き、右側に大きな水平線と空白を残しました。切断点を左寄りの主役近くに置きつつ、紐が右へほどけることで視線が広い余白へ流れます。Hero のコピーや検索 UI が近くに来ても邪魔しないよう、右側は密度を落としています。

モバイル版は、上=空、中=切断の瞬間、下=地平線と道の三層構成です。縦画面でもキリさんの頭部が潰れないよう、中央に大きく配置し、下部の道で「次に進む」感覚を足しています。

## ライト/ダークの色設計

- ライト: `#fbf8f3` に `#0a7c7c` の薄い朝霞を重ねた空。キリさんは v3 マスコットと同じ `#0a7c7c`, `#1a1f2e`, `#5e6a82`, `#b85c3d`, `#fbf8f3`。
- ダーク: `#131c2e` から `#1a2540` の夜空。刃は `#5cb9b9`、輪郭と月明かりは `#aab4c8` に統一して、5色以内で同じキャラに見えるようにしました。

## モバイル縦への組み直し方針

横長版の要素を縮めるだけでなく、紐の切断を画面中央に再配置しました。契約カードは2枚に減らし、遠景と道を下へ逃がして、スマホの狭い幅でも「空が広い」「紐が切れた」「キリさんが主役」が同時に読めるようにしています。

## 想定外の使い方

横長版は Hero だけでなく、ブログのOGP下地や解約完了ページのヘッダーにも使えます。モバイル版は空状態やオンボーディングの1枚目にも流用可能です。契約カードに実在ロゴを入れていないため、特定サービスに寄らずサイト全体のブランドビジュアルとして使えます。
