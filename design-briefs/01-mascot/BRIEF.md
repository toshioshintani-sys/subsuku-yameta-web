**ステータス：** `[~] 再依頼中（v1 は判別性不足で差し戻し）`
**優先度：** ★★★★★（サイト全体の顔・他のブリーフでも再利用される）
**納品期日：** 着手から1週間以内

## ⚠️ 改訂理由（必読・v1 の失敗）

初回（v1）の納品は **「一目で何を描いているか分からない」** という致命的問題で差し戻しになりました。
- はさみの刃・ピボット・持ち手を **全部キャラの顔と体に割り当てた**結果、
- 玉ねぎ・カニ・トンボ・甲虫 に見えてしまい、「はさみ」と認識できなかった。

### v2 の核心方針：「映画泥棒」型の擬人化

日本の著作権啓発キャラ「NO MORE 映画泥棒」を **構造の参考** にします（見た目のコピーは禁止・後述）。

```
映画泥棒：  頭 = ビデオカメラ  /  体 = 人間  → 一目で「カメラ人間」
新キリさん： 頭 = はさみ        /  体 = 人間型 → 一目で「はさみ人間」
```

**鉄則：頭部を完全に「はさみ」にする。体は人間型（手足あり）。**
これにより「頭がはさみ ＝ 切る人 ＝ サブスクをやめさせてくれる存在」が一目で伝わります。

### ⚠️ 著作権の絶対ルール

- 映画泥棒の **見た目・ポーズ・配色・不気味さ をコピーしてはいけない**
- 参照するのは **「道具が頭・体が人間」という擬人化の構造のみ**
- はさみ頭は **完全オリジナル** でデザインすること
- 映画泥棒を想起させる要素（カメラ・赤黒の警告色・あの顔）は一切入れない

## 1. 制作依頼の概要

「サブスクやめた」（https://sabusuku.netlify.app）の **公式マスコットキャラクター** を制作してください。

このキャラはサイト全体で再登場します：
- HomePage の使い方ガイド
- 404 ページ
- Empty State（検索結果0件など）
- 「やめたつもり貯金ゲーム」終了画面
- ブログ記事の挿絵

つまり **サイトの "顔"** です。1度きりのイラストではなく、長く付き合える愛着のあるキャラクターを目指してください。

---

## 2. キャラクター設定

### 構造：頭＝はさみ / 体＝人間型（最重要）

```
   ✂   ← 頭部：はさみ（一目ではさみと分かること最優先）
  ╱│╲
   ●    ← 胴体：シンプルな人間型
  ╱ ╲   ← 手足：あり（表情やポーズを作れる）
```

#### 頭部（はさみ）の描き方

- **閉じたはさみ** を基本とする（開くと「葉・羽・角」に誤認されやすい）
- はさみの「刃の尖り」「持ち手の輪（2つの穴）」「ピボット（中央のねじ）」が
  **はさみの形として成立** していること
- 持ち手の輪は **目** として使ってもよい（カメラのレンズが目に見えるのと同じ発想）
- ティール `#0a7c7c` の金属刃 ＋ 温かい白 `#fbf8f3` の持ち手で「はさみ」を明示

#### 体（人間型）の描き方

- シンプルな胴体＋腕＋脚（細部は最小限・シルエット重視）
- 服装は控えめ（スーツでもカジュアルでも可・ただし地味な単色）
- 体の配色は背景に馴染むニュートラル（`#5e6a82` や `#fbf8f3` 系）
- 体が主張しすぎて頭（はさみ）より目立たないこと

### 性格設定（ポーズ・表情に反映）

- 親切で押し付けがましくない
- 知性的（理屈で説明できる）
- 少し皮肉屋（業界の闇を知っている）
- でも基本的には味方
- 落ち着いていて、慌てない
- 子供っぽくはないが、堅苦しくもない

### 性別・年齢

なし（ジェンダーレス・年齢不詳）。

### ⛔ v1 で失敗したのでやってはいけないこと

- ❌ はさみを「開いた V 字」にする（葉・羽・トンボに見える）
- ❌ 顔を主役にしてはさみ構造を後付けする（順序が逆）
- ❌ 持ち手の輪を「顔の下の2つの球」にする（玉ねぎに見える）
- ❌ 頭と体の区別がつかない一体型シルエット

## 3. 必要なバリエーション（5表情）

以下の5パターンを制作してください：

頭（はさみ）は固定し、**体のポーズと表情** で5パターンを作る（映画泥棒も頭は同じでポーズで演じる）：

| ファイル名 | ポーズ・表情 | 使用シーン |
|---|---|---|
| `mascot-smile.svg` | 穏やかに立つ・正面・軽く微笑む | デフォルト・Hero 等 |
| `mascot-thinking.svg` | 腕を組む or 顎に手を当て考える | 「使い方ガイド」セクション |
| `mascot-celebrate.svg` | 両腕を上げて喜ぶ | 解約完了・ゲーム高スコア |
| `mascot-lost.svg` | 肩をすくめて困る・きょとん | 404 ページ・Empty State |
| `mascot-cutting.svg` | 体をかがめ、頭のはさみ（or 手に持った別のはさみ）で紐を切る | HomePage Hero |

## 4. ビジュアル仕様

### 配色

`_STYLE_GUIDE.md` § 4 のパレットを厳守。
特に推奨される使い方：
- **メイン色：** `#0a7c7c`（accent ティール）→ はさみの刃
- **アクセント：** `#fbf8f3`（背景の温かい白）→ はさみの持ち手
- **アクセント2：** `#b85c3d`（loss テラコッタ）→ 切られる対象（紐・札）
- **線：** `#1a1f2e`（深い藍黒）→ 輪郭線

3-4色で構成。シンプルに。

### スタイル方向性

- **フラットイラスト**（写実的でなく、装飾的でもなく）
- **微細なシャドウ** で立体感（深い影は使わない）
- **角を丸める**（鋭利すぎない）
- **線は均一の太さ**（1.5-2.5px）

### サイズ

- SVG: viewBox は **0 0 200 200**（正方形・後でレスポンシブ対応）
- PNG: 1x = 200x200, 2x = 400x400, 3x = 600x600
- 透過背景

### スタイル参考（雰囲気だけ・寄せすぎない）

- **Duolingo の Duo** くらいの愛らしさ
- **Notion の絵文字風アイコン** くらいの抽象度
- **MailChimp の Freddie** くらいの個性
- ※ パクリは厳禁・あくまで方向性の参考

## 5. 重要な制約

### やってほしいこと

- ✅ 一目で「これは "サブスクやめた" のキャラだ」と認識できる独自性
- ✅ 5表情に **一貫性**（同じキャラだとわかる）
- ✅ 表情差分は **目・口・姿勢** で表現（全体を作り直さない）
- ✅ 拡大しても潰れない SVG 品質

### やってはいけないこと

- ❌ 既存キャラへの過度な類似（Duo・Freddie・Mailchimp パンダなど）
- ❌ 怖い・攻撃的な表情（はさみは武器ではない・優しい道具）
- ❌ サブスク企業ロゴの模倣
- ❌ 過度に幼児的（チャラさ・かわいすぎ）
- ❌ ジェネリックなフリー素材っぽさ（unDraw 系）

## 6. 採用基準（納品前に Codex 自身がチェック）

### 🥇 最重要：判別性テスト（これを最初に通すこと）

- [ ] **完成 SVG を PNG 化して、予備知識のない人が見て「はさみ（の人）」と答えられるか**
- [ ] 玉ねぎ・カニ・トンボ・甲虫・葉っぱ に見えないか
- [ ] 頭部が明確に「はさみ」と認識できるか
- [ ] 体が「人間型キャラ」と認識できるか
- [ ] 頭（はさみ）と体（人間）が視覚的に分離しているか

**この判別性テストを通らない限り、他の項目を満たしても不採用。**
Codex 自身が PNG レンダリングして客観確認すること（v1 はこれを怠った）。

### その他

- [ ] 5ポーズすべて納品されている
- [ ] 同一キャラとして認識できる一貫性がある（頭のはさみは固定・ポーズで差分）
- [ ] 配色がスタイルガイド準拠
- [ ] ファイル名規則準拠（SVG のみ・PNG 不要）
- [ ] 背景が透過されている
- [ ] BAE 設計憲法に違反していない（煽り・攻撃性なし）
- [ ] 映画泥棒の見た目・配色をコピーしていない（構造のみ参照）

## 8. 納品方法（PR ベース）

### ブランチ運用

1. `main` から `codex/01-mascot` ブランチを切る
2. 下記ファイルを作成・コミット
3. PR を出す（タイトル：「Codex: Mascot - 5 expressions (BRIEF 01)」）
4. PR Description に DESIGN_NOTES.md の内容＋採用基準セルフチェックを記載

### 納品先・ファイル名（厳守）

`design-briefs/01-mascot/output/` 配下に：

```
output/
├── mascot-smile.svg
├── mascot-thinking.svg
├── mascot-celebrate.svg
├── mascot-lost.svg
├── mascot-cutting.svg
└── DESIGN_NOTES.md ← Codex が制作意図を書く（後述）
```

**PNG は不要**（SVG のみ・viewBox でレスポンシブ対応）。

### DESIGN_NOTES.md に書くべきこと

```markdown
# 制作ノート（Codex から俊雄さんへ）

## キャラクターのコンセプト
（このキャラに込めた意図・性格設定・なぜこの形にしたか）

## 各表情の使い分け提案
（smile / thinking / celebrate / lost / cutting がそれぞれどの場面で輝くか）

## 想定外の使い方
（俊雄さんがまだ気づいていない、このキャラの使い方の可能性）

## 名前の提案（任意）
（キャラに名前をつけるなら何が良いか）
```
