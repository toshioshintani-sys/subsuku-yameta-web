# BRIEF 01：マスコットキャラクター制作依頼

**ステータス：** `[ ] 未着手`
**優先度：** ★★★★★（サイト全体の顔・他のブリーフでも再利用される）
**納品期日：** 着手から1週間以内

---

## 1. 制作依頼の概要

「サブスクやめた」（https://sabusuku.netlify.app）の **公式マスコットキャラクター** を制作してください。

このキャラはサイト全体で再登場します：
- HomePage の使い方ガイド
- 404 ページ
- Empty State（検索結果0件など）
- 「やめたつもり貯金ゲーム」終了画面
- ブログ記事の挿絵

つまり **サイトの "顔"** です。1度きりのイラストではなく、長く付き合える愛着のあるキャラクターを目指してください。

---

## 2. キャラクター設定

### モチーフ：はさみ（Scissors）

「サブスクやめた」のロゴアイコンは **はさみ ✂** です。
このはさみを擬人化してください。

なぜはさみか？
- サブスクの紐を「切る」道具
- 鋭利だが繊細
- 「やめる」決断の象徴

### 性格設定（ビジュアルに反映させる）

- 親切で押し付けがましくない
- 知性的（理屈で説明できる）
- 少し皮肉屋（業界の闇を知っている）
- でも基本的には味方
- 落ち着いていて、慌てない
- 子供っぽくはないが、堅苦しくもない

### 性別・年齢の指定

なし（ジェンダーレス・年齢不詳）。
擬人化と言っても、極端な人型である必要はありません。
**はさみ自体がキャラクター** という方向性も歓迎します。

## 3. 必要なバリエーション（5表情）

以下の5パターンを制作してください：

| ファイル名 | 表情・姿勢 | 使用シーン |
|---|---|---|
| `mascot-smile.svg` / `.png` | 穏やかに微笑む・正面 | デフォルト・Hero 等 |
| `mascot-thinking.svg` / `.png` | 顎に手（刃？）を当てて考えている | 「使い方ガイド」セクション |
| `mascot-celebrate.svg` / `.png` | 両手を上げて喜ぶ | 解約完了・ゲーム高スコア |
| `mascot-lost.svg` / `.png` | きょとんと困った顔 | 404 ページ・Empty State |
| `mascot-cutting.svg` / `.png` | サブスクの「紐」をチョキンと切る瞬間 | HomePage Hero |

## 4. ビジュアル仕様

### 配色

`_STYLE_GUIDE.md` § 4 のパレットを厳守。
特に推奨される使い方：
- **メイン色：** `#0a7c7c`（accent ティール）→ はさみの刃
- **アクセント：** `#fbf8f3`（背景の温かい白）→ はさみの持ち手
- **アクセント2：** `#b85c3d`（loss テラコッタ）→ 切られる対象（紐・札）
- **線：** `#1a1f2e`（深い藍黒）→ 輪郭線

3-4色で構成。シンプルに。

### スタイル方向性

- **フラットイラスト**（写実的でなく、装飾的でもなく）
- **微細なシャドウ** で立体感（深い影は使わない）
- **角を丸める**（鋭利すぎない）
- **線は均一の太さ**（1.5-2.5px）

### サイズ

- SVG: viewBox は **0 0 200 200**（正方形・後でレスポンシブ対応）
- PNG: 1x = 200x200, 2x = 400x400, 3x = 600x600
- 透過背景

### スタイル参考（雰囲気だけ・寄せすぎない）

- **Duolingo の Duo** くらいの愛らしさ
- **Notion の絵文字風アイコン** くらいの抽象度
- **MailChimp の Freddie** くらいの個性
- ※ パクリは厳禁・あくまで方向性の参考

---

## 5. 重要な制約

### やってほしいこと

- ✅ 一目で「これは "サブスクやめた" のキャラだ」と認識できる独自性
- ✅ 5表情に **一貫性**（同じキャラだとわかる）
- ✅ 表情差分は **目・口・姿勢** で表現（全体を作り直さない）
- ✅ 拡大しても潰れない SVG 品質

### やってはいけないこと

- ❌ 既存キャラへの過度な類似（Duo・Freddie・Mailchimp パンダなど）
- ❌ 怖い・攻撃的な表情（はさみは武器ではない・優しい道具）
- ❌ サブスク企業ロゴの模倣
- ❌ 過度に幼児的（チャラさ・かわいすぎ）
- ❌ ジェネリックなフリー素材っぽさ（unDraw 系）

## 7. 納品方法

`design-briefs/01-mascot/output/` 配下に：

```
output/
├── mascot-smile.svg
├── mascot-smile@1x.png
├── mascot-smile@2x.png
├── mascot-smile@3x.png
├── mascot-thinking.svg
├── mascot-thinking@1x.png
├── ... (以下同様で 5表情 × 4ファイル = 20ファイル)
└── DESIGN_NOTES.md ← Codex が制作意図を書く（後述）
```

### DESIGN_NOTES.md に書くべきこと

```markdown
# 制作ノート（Codex から俊雄さんへ）

## キャラクターのコンセプト
（このキャラに込めた意図・性格設定・なぜこの形にしたか）

## 各表情の使い分け提案
（smile / thinking / celebrate / lost / cutting がそれぞれどの場面で輝くか）

## 想定外の使い方
（俊雄さんがまだ気づいていない、このキャラの使い方の可能性）

## 名前の提案（任意）
（キャラに名前をつけるなら何が良いか）
```

## 8. 想像を超えてください

このマスコットがサブスクやめたを **アプリストア No.1** に押し上げる中核です。

俊雄さんと私が想像していない、しかし的確で愛されるキャラクターを Codex の発想で生み出してください。

「はさみ」というモチーフを超えてもOKです。
ただし「やめる」という決断を擬人化した存在であることだけは外さないでください。
