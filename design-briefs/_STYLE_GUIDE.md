# サブスクやめた — Style Guide（Codex 必読）

> このドキュメントは「サブスクやめた」のビジュアル世界観を Codex に伝えるための憲法です。
> 各 BRIEF を読む前にまずこれを完全に理解してください。

---

## 1. サイトの本質

「サブスクやめた」は、現代人が知らぬ間に増やしてしまった月額固定費を、
**静かに・誠実に・確実に** 解約させてくれるためのインデックスサイトです。

訪問者の心理状態：
- 「気付いたら毎月10,000円以上サブスクに払っていた」
- 「解約ボタンが見つからなくて諦めかけている」
- 「もう余計な情報は要らない、ただ解約させてほしい」

サイトが訪問者にしてあげるべきこと：
- 解約ページへの最短距離を示す
- 余計な煽りで疲労させない
- 「やめた後の選択肢」も静かに提示する

## 2. ブランドキーワード（ビジュアルに込めるべき感情）

| キーワード | 視覚化のヒント |
|---|---|
| **自由（Liberation）** | 鎖から解き放たれる・羽ばたく・荷物を下ろす |
| **静謐（Stillness）** | 余白の美・少ないストローク・ノイズなし |
| **信頼（Trust）** | 整った構造・正確な比率・誠実なライン |
| **温かさ（Warmth）** | 微温（cold）でも熱（hot）でもない・人肌の感じ |
| **解放感（Relief）** | 重荷が消える瞬間・ふっと軽くなる感覚 |
| **知性（Intellect）** | 計算された配色・余計を削ぎ落とした形 |

---

## 3. 視覚言語の核 — はさみ（Scissors）

サイトのアイコンは **はさみ（✂）** です。

これは：
- サブスクの紐を **切る** 道具
- 鋭利だが繊細
- 「やめる」決断の象徴

はさみは **マスコット化** されており、サイト全体で再登場します。
キャラクターとしての性格：
- 親切で押し付けがましくない
- 知性的（理屈で説明できる）
- 少し皮肉屋（業界の闇を知っている）
- でも基本的には味方

## 4. 配色（厳守）

サイトは OKLCH カラーシステムを採用。Codex も以下の色のみ使うこと：

> **2026-08-04 改訂（可読性優先 × ナッジ集中）。**
> 改訂前の記載値（#0a7c7c・ダーク #131c2e 等）は実装のどこにも存在せず、
> ドキュメントと実装が食い違っていた。以下は `src/index.css` の実値と一致している。

### ライトモード

```
プライマリ（解約・完了）:
  メイン:    #2c5f4a
  ホバー:    #204636
  ソフト:    #e3ece6

ナッジ（次の一手・回遊）:
  面:        #f0b449
  面上の文字: #3d2102
  淡面:      #fdf0d9
  淡面の文字: #6b3a05

ニュートラル:
  背景:      #f4f0e6
  サーフェス: #fffdf9
  テキスト:   #17212b
  サブテキスト: #4b5765
  補助テキスト: #6d7885  ← これより薄い灰は使わない
  ボーダー:   #e2dbc8
```

### ダークモード

```
ダークモード:
  背景:      #141a20
  サーフェス: #1d242c
  プライマリ: #79c9a5
  テキスト:   #f2efe8
  サブテキスト: #b9c0c8
  ボーダー:   #2b333c
```

### 損失の見せ方（改訂で変わった点）

**損失に色を持たせない。** 赤・テラコッタの面は廃止し、インクと数字の大きさで示す。
ページ上の暖色をサフラン（ナッジ）だけにすることで、次の一手が必ず勝つようにする。

**サフランは面で使い、1画面に強い段は1つだけ。** 2つ以上あると効かない。
文字色に使うと読めないので、塗りの上には濃い茶インク（#3d2102）を置く。

### 使用ルール

- **1イラスト = 最大5色まで**（影とハイライト含む）
- 派手なグラデーション禁止（控えめなグラデは OK・accent カラー内で）
- 純黒・純白の使用禁止（必ず色味を含める）

## 5. タイポグラフィ（イラスト内に文字を入れる場合）

- 日本語: **Noto Sans JP**
- 英数字: **Inter**（または近似フォント）
- モノスペース: **JetBrains Mono**（数字・金額）

イラストに文字を入れる時は控えめに。基本はビジュアルのみで語る。

---

## 6. 線の精度

- **ストローク幅は統一**（1.5px / 2px / 2.5px の3段階のみ）
- **角は丸める**（rounded corners・冷たい印象を避ける）
- **完璧な対称を避ける**（人間味を残す）

## 8. 絶対に避けるべき表現

- ❌ ランキングUI（★スコア・順位バッジ）

- ❌ 派手なグラデーション（虹色・レインボー）

## 9. ファイル仕様

### 推奨フォーマット

- **アイコン・マスコット**：SVG（拡縮自在）+ 透過 PNG（fallback）
- **イラスト（Hero・404・Empty）**：SVG 推奨・PNG/WebP 可
- **背景画像**：WebP（軽量）

### サイズと品質

- SVG: viewBox 明記・stroke="currentColor" でテーマ追従可能に
- PNG: 1x / 2x / 3x の3サイズ（@1x, @2x, @3x サフィックス）
- WebP: 90% 品質・モバイル想定で 1920px 幅まで

### ファイル名規則

- 小文字・ハイフン区切り（例：`mascot-smile.svg`）
- スネークケース禁止・キャメルケース禁止
- 日本語ファイル名禁止

## 10. 採用基準（Codex 自身でチェック）

### 🥇 最重要：判別性テスト（全ブリーフ共通・最初に通す）

**2026-05-28 追加。BRIEF 01 v1 が「玉ねぎ・トンボに見える」失敗をしたため必須化。**

- [ ] **完成 SVG を PNG 化して、予備知識のない人が見て「何を描いたか」を正しく答えられるか**
- [ ] 意図したモチーフ以外のもの（玉ねぎ・カニ・虫 等）に誤認されないか
- [ ] Codex 自身が PNG レンダリングして客観確認したか

**判別性テストを通らないイラストは、配色や技術が完璧でも不採用。**
「作り手は何を描いたか知っているから分かる」が、初見の人には伝わらないことがある。
必ず "予備知識ゼロの視点" で自分の絵を疑うこと。

### その他

- [ ] 配色がガイドの6色（+ ダーク6色）内に収まっている
- [ ] 禁止表現（§ 8）が含まれていない
- [ ] ファイル名規則（§ 9）に従っている
- [ ] viewBox / アスペクト比が指定通り
- [ ] BAE 設計憲法に違反していない（解約導線を脅かさない・煽らない）

満たさない項目があれば、Codex 側で修正してから納品。

## 11. 想像を超えてください

俊雄さんは「想像を超える出来栄え」を期待しています。

これは制約に縛られすぎて凡庸になるな、という意味です。
ガイドの **不可侵領域は守る**（解約導線・煽らない・配色）。
ただし、**ガイドが指定していない領域では大胆に**。

具体例：
- Hero イラストに何を描くかは Codex の発想に委ねる
- マスコットの姿勢・表情のバリエーションは増やしてもOK
- 文字なしで意味を伝える挑戦をしてほしい

Codex の創造性が、サブスクやめたを **アプリストア No.1** に押し上げます。
