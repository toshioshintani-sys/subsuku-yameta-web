## 0. 概要（Overview）

トップページ（`/`＝`src/pages/HomePage.jsx`）の**見た目と挙動を刷新**する。情報の序列・解約導線・第一印象という「不可侵領域」は1mmも動かさず、**初見の分かりやすさ**と**操作の手触り**、そして**行動経済学的なナッジ**と**人間工学的なボタン配置**を足して、見た目を一段引き上げる。

中心になるのは次の3つのライブ機能：
1. **ヒーロー検索**（サービス名を打つ → その解約ページへ直行できると一目で分かる typeahead）
2. **固定費アンカー＋ナッジ**（年額アンカリング → 5年総額で損失回避 → 「いちばん効く一手」で具体化）
3. **親指ゾーン固定CTAバー**（スクロールしても下部に残る主要導線）

## 1. このバンドのデザインファイルについて（About the Design Files）

- 同梱の `Canvas.dc.html` は **HTMLで作られたデザイン参照（プロトタイプ）** です。**そのまま本番に貼るものではありません。**
- タスクは、この参照を**既存コードベースの作法（React 関数コンポーネント＋ CSS Modules＋ `react-router` ＋ `src/data/services.js`）で“作り直す”こと**。
- `Canvas.dc.html` は「Design Component」という独自ランタイム（`support.js`）で動くため、ロジックは `class Component extends DCLogic` 内にあります。**ロジックの考え方（state・計算式・ハンドラ）を読み取り、通常の React（useState/useMemo）へ移植**してください。HTMLの構造とインラインstyleは、**見た目の仕様書**として読んでください。
- ブラウザで `Canvas.dc.html` を直接開けば、決定版（最下段のフレーム「サブスクやめた｜Home（決定版・スクロール可）」）で実際に検索・計算機・年/月切替・解約候補の自動切替まで触れます。**まずこれを触ってから実装に入ること。**

## 6. 状態と挙動（State / Behavior）

React に移植する state（`useState` ＋ `useMemo`）：

| state | 初期値 | 説明 |
|---|---|---|
| `q` | `''` | 検索クエリ |
| `plans` | `{netflix:1, spotify:0, youtube:0}` | 各サービスの選択プラン index |
| `on` | `{netflix:true, spotify:true, youtube:true}` | 計算機に含めるか |
| `period` | `'year'` | `'year'` ＼ `'month'` |
| `sortMode` | `'pop'` | Top一覧の並び（任意機能） |

派生値（`useMemo`）：
- `monthly = Σ(on の各サービスの 選択プラン価格)`
- `target = period==='year' ? monthly*12 : monthly`
- `totalText = '¥' + target.toLocaleString('ja-JP')` ← **見出しは常にこれを表示（即時・正確）**
- `fiveYearText = '¥' + (target*5).toLocaleString('ja-JP')`
- `topCut = on のうち 年額(price*12) 最大のサービス` → 名前＋`'¥'+annual.toLocaleString()`
- `searchResults = SERVICES.filter(s => (s.name+' '+s.kana).includes(q)).slice(0,4)`

挙動：
- **検索**：入力ごとに絞り込み（前方/部分一致・かな別名も対象）。結果行クリック → そのサービスの解約ページ（`/service/:id` or `cancelUrl`）。
- **トグル/プラン/年月**：変更で `totalText`・`fiveYearText`・`topCut`・CTAバー金額が**即更新**。
- **重要（バグ回避）**：合計表示を `requestAnimationFrame` のカウントアップ等に依存させない。**毎レンダー `target()` を直接描画**する（プロトで一度この罠を踏んでいる）。アニメを足すなら表示の正しさと分離すること。
- **hover**：一覧/EasyWins の行は持ち上げ（上記 box-shadow）。
- **レスポンシブ**：モバイル1カラム。デスクトップは中央寄せ＋最大幅。CTAバーはモバイルで sticky bottom、デスクトップはヒーロー内 or 追従いずれか（既存作法に合わせる）。
